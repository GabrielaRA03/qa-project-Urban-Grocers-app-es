# Proyecto Urban Grocers 

#Descripción
Este proyecto contiene pruebas automatizadas para la API de Urban Grocers.
verifica la funcionalidad de kits y usuarios con pruebas automatizadas con Python y Pytest

#Documentación de la API
se encuentra en: servidor de pruebas(apidoc)/docs/

#tecnologias utilizadas
-Python
-pytest
-requests

#como ejecutar las pruebar
1.instalar las dependencias: pip install pytest request
2.Configurar la URL del servidor en el archivo configuration.py
3.Ejecutar las pruebas con pytest
